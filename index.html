AI Agents in Practice

A one-day course on using AI agents in your research. An AI agent is an assistant that can read your files, run programs and check its own work. You learn how agents work, how to give them good tasks, how to use them safely and how to check what they produce.

Who it is for

Researchers from NWO-I institutes

The day is for about 50 to 60 researchers from NWO-I institutes. Most work outside computer science, in fields such as physics, astronomy, earth and ocean sciences, mathematics, chemistry and the life sciences.

You do not need a background in computer science. We explain every term the first time we use it. The examples come from research work. Think of a messy data file and a plot, an analysis script, a LaTeX paper, a literature search or a grant text.

What you will be able to do

After the day, you can…

  1. How AI agents work. Say what happens when you type a request into an agent, and what an agent can and cannot see or do.
  2. Working effectively with an agent. Write a task description that an agent can follow. Give it the right context, steer it while it works and recover when it goes wrong.
  3. Skills and safety. Explain what a skill is, judge a shared skill before you install it and choose a safe setup for your own work.
  4. Larger work, and checking the results. Split a larger task, keep long work on track across sessions, recognise the typical failures and check results before you trust them.
