Who it is for

Researchers at NWO-I institutes

The lectures are designed for researchers and students at NWO-I institutes, from any field. You do not need a background in computer science.

What you will be able to do

After the day, you can…

  1. How AI agents work. Say what happens when you type a request into an agent, and what an agent can and cannot see or do.
  2. Getting good results from an agent. Write a task description that an agent can follow. Give it the right context, steer it while it works and recover when it goes wrong.
  3. Agent Skills and Safety. Know what Agent Skills are, and how to use agents safely.
  4. Bigger projects, and when to trust the output. Use agents on work that takes several days, spot the typical mistakes they make, and check their output before you rely on it.

Before you come

Come with a working agent

  • Bring a laptop and its charger.
  • Install the Claude desktop app (Claude Code), the ChatGPT desktop app (Codex) or your favourite agent app, and log in.
  • Optional. Turn off the setting that lets the provider use your data to improve its models.
